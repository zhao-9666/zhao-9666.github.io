和参考代码的对应关系

参考实现 xor_tensorflow.py 用四个 0/1 样本构成 XOR：00→0，01→1，10→1，11→0。这里把四个样本换成四只股票，两条输入换成「资金流向」与「市场情绪」，标签换成「跌 / 涨」——结构完全一致，因此线性模型无解，必须靠隐藏层折叠空间。

x = [资金流向, 市场情绪]→h = σ(x·W + b₁)→z = h·v + b₂→p = σ(z)→BCE(z, y)→Adam 更新 7 个参数

梯度由手写反向传播给出：∂L/∂z = (σ(z) − y)/N，再逐层乘以上一层的激活与 Sigmoid 导数 h(1−h)。初始值与 Python 端一致：W=[[2,−2],[−2,2]]，b₁=[−1,−1]，v=[3,3]，b₂=−2.5。训练约 300 轮后，四只股票的预测概率收敛到 0.03 / 0.97 / 0.97 / 0.03，全部判对。所有数值都在浏览器本地计算，不上传任何数据。

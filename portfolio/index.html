        不想连仓库？也可以把作品信息保存成文件，手动拖到 GitHub 网页上。

          方案 A · Fine-grained Token（推荐）

          只授权这一个仓库，最安全。

          1. 打开 创建 Fine-grained token ↗
          2. Token name 随便填，Expiration 选一个过期时间
          3. Repository access 选 Only select repositories → 下拉里勾选 zzj903.github.io
          4. Permissions 是折叠的，要先点一下展开（页面上写着 Permissions，右边有箭头）→ 进入 Repository permissions
          5. 在列表里找到 Contents，右侧下拉改成 Read and write（其余保持 No access）
          6. 拉到页面底部点 Generate token，复制 github_pat_ 开头的一整串

          找不到 Permissions？99% 是因为还没勾选仓库。必须先在第 3 步把仓库勾上， Permissions 区域才会出现可编辑的权限列表；它默认是折叠状态，点标题才能展开。 中文界面叫「权限 → 仓库权限 → 内容 → 读取和写入」。

          方案 B · Classic Token（更省事，权限更大）
          1. 打开 创建 Classic token ↗（链接已自动勾好 repo）
          2. Note 随便填，Expiration 可设为 No expiration
          3. 确认 Select scopes 里只勾了最上面的 repo，其余不勾
          4. 页面底部点 Generate token，复制 ghp_ 开头的一整串

          Classic token 没有「Repository permissions」这一项，只有 scopes 勾选框，因此不需要设 Contents。它对你账号下所有仓库都有写权限，泄露风险比方案 A 大。

          Token 只保存在你这台电脑的浏览器里（localStorage），不会上传到任何服务器。但请不要在公共电脑上保存。
